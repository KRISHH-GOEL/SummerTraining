# Lesson 02 – Data Manipulation, Aggregation & Time Series

## 📌 Objective

The objective of this lesson was to learn advanced data manipulation techniques in Pandas. This lesson focused on grouping and aggregating data, combining multiple datasets, applying custom operations, and working with time series data.

These concepts are fundamental for Exploratory Data Analysis (EDA), Data Cleaning, Business Intelligence, and Machine Learning workflows.

---

## 📚 Topics Covered

### Data Cleaning

- `dropna()`
- `fillna()`
- `drop_duplicates()`
- `astype()`
- `rename()`

### Grouping & Aggregation

- `groupby()`
- `agg()`
- `pivot_table()`
- `crosstab()`

### Merging Data

- `merge()`
- `join()`
- `concat()`

Join Types:
- Inner Join
- Left Join
- Right Join
- Outer Join

### Apply & Map Functions

- `apply()`
- `map()`
- `applymap()`

### Time Series

- `DatetimeIndex`
- `resample()`
- `rolling()`
- `shift()`

---

## 🎯 Learning Outcomes

After completing this lesson, I can:

- Clean datasets efficiently.
- Group data and calculate aggregate statistics.
- Create pivot tables and cross-tabulations.
- Merge multiple datasets using different join techniques.
- Apply custom functions to Series and DataFrames.
- Work with datetime data.
- Perform resampling and rolling window calculations.
- Shift time-series data for analysis.

## ⚡ Quick Revision

| Function | Purpose |
|----------|---------|
| `groupby()` | Group rows based on column values |
| `agg()` | Perform multiple aggregations |
| `pivot_table()` | Create summarized pivot tables |
| `crosstab()` | Frequency table |
| `merge()` | Combine DataFrames using keys |
| `join()` | Join DataFrames by index |
| `concat()` | Concatenate DataFrames |
| `apply()` | Apply function to rows/columns |
| `map()` | Map values in a Series |
| `applymap()` | Apply function to every DataFrame element |
| `DatetimeIndex` | Date-based indexing |
| `resample()` | Change time frequency |
| `rolling()` | Rolling window calculations |
| `shift()` | Shift data forward/backward |
