# Lesson 01 – Data Collection & Data Sources

## 📌 Objective

The objective of this lesson was to understand the different types of data, identify reliable sources for obtaining datasets, and learn how to load data into Python for analysis.

Data collection is the first step in every Data Science and Machine Learning project. The quality of collected data directly influences the quality of analysis and predictive models.

---

## 📚 Topics Covered

### Introduction to Data Wrangling

- What is Data Wrangling?
- Why Data Wrangling is Important

### Types of Data

- Structured Data
- Semi-Structured Data
- Unstructured Data

### Public Data Sources

- Kaggle
- UCI Machine Learning Repository
- data.gov.in
- World Bank Open Data

### Loading Datasets

- CSV Files
- Excel Files
- JSON Files

---

## 🎯 Learning Outcomes

After completing this lesson, I can:

- Differentiate between structured, semi-structured, and unstructured data.
- Identify reliable public dataset repositories.
- Understand where datasets for ML projects originate.
- Load datasets into Pandas for further analysis.
