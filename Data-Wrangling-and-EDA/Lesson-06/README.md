# Lesson 06 – Exploratory Data Analysis (EDA)

## 📌 Objective

The objective of this lesson was to understand how to systematically explore a dataset before building Machine Learning models.

Exploratory Data Analysis (EDA) helps identify patterns, detect anomalies, understand feature relationships, and derive meaningful business insights.

This lesson demonstrates the standard EDA workflow followed in Data Science projects.

---

## 📚 Topics Covered

### EDA Checklist

- Dataset Shape
- Dataset Information
- Data Types
- Missing Values
- Duplicate Records
- Unique Values
- Statistical Summary

### Univariate Analysis

- Histogram
- KDE Plot
- Count Plot
- Bar Chart
- Pie Chart
- Box Plot

### Bivariate Analysis

- Scatter Plot
- Box Plot by Category
- Violin Plot
- Correlation Analysis

### Multivariate Analysis

- Pair Plot
- Correlation Heatmap

### Business Insights

- Understanding distributions
- Identifying relationships
- Detecting trends
- Drawing actionable conclusions

---

## 🎯 Learning Outcomes

After completing this lesson, I can:

- Perform a complete EDA workflow.
- Analyze feature distributions.
- Compare variables.
- Understand feature relationships.
- Detect skewness and outliers.
- Interpret charts instead of only creating them.
- Generate business insights.
