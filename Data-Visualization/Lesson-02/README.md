# Lesson 02 – Basic Charts using Matplotlib

## 📌 Objective

The objective of this lesson was to learn how to visualize different types of data using the most commonly used charts in Matplotlib.

Selecting the appropriate chart is essential for communicating insights effectively. This lesson introduces several fundamental chart types and demonstrates when each should be used.

---

## 📚 Topics Covered

### Line Plot
- Trend Analysis
- Time Series Visualization

### Bar Chart
- Comparing Categories
- Vertical & Horizontal Bars

### Scatter Plot
- Relationship Between Variables
- Detecting Correlation

### Histogram
- Distribution of Numerical Data

### Pie Chart
- Percentage Distribution

### Area Chart
- Cumulative Trends

---

## 🎯 Learning Outcomes

After completing this lesson, I can:

- Create different types of charts using Matplotlib.
- Select the appropriate chart for different datasets.
- Customize plots with titles, labels, legends, and grids.
- Interpret visualizations and derive business insights.
