# Lesson 03 – Advanced Matplotlib

## 📌 Objective

The objective of this lesson was to learn advanced customization techniques in Matplotlib for creating professional-quality visualizations.

Effective visualizations require more than plotting data—they need proper layout, annotations, styling, multiple axes, and high-quality output suitable for reports and presentations.

This lesson demonstrates how to customize figures, organize multiple plots, annotate important values, and export publication-ready charts.

---

## 📚 Topics Covered

### Figure Customization

- Figure Size
- DPI
- Axis Limits
- Tick Customization
- Grid Customization

### Multiple Plots

- subplot()
- subplots()
- Shared Axes

### Twin Axes

- Secondary Y-Axis

### Plot Annotation

- annotate()
- text()

### Styling

- Line Styles
- Colors
- Markers
- Transparency

### Exporting Figures

- savefig()
- Image Quality
- Tight Layout

## 🎯 Learning Outcomes

After completing this lesson, I can:

- Create professional-quality visualizations.
- Display multiple charts in a single figure.
- Use dual-axis plots.
- Highlight important observations with annotations.
- Export high-resolution figures.
- Build report-ready visualizations.
