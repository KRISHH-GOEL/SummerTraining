# Lesson 01 – Matplotlib Fundamentals

## 📌 Objective

The objective of this lesson was to understand the fundamentals of Matplotlib, Python's most widely used visualization library.

Visualization is one of the most important stages of Data Analysis because it helps uncover patterns, trends, distributions, and relationships that may not be obvious from raw data.

This lesson introduces the architecture of Matplotlib and demonstrates how to create simple yet effective plots.

---

- What is Matplotlib?
- Why Matplotlib?
- Importing Matplotlib

### Matplotlib Architecture

- Figure
- Axes
- Artist

### Basic Plot

- Creating a Line Plot
- Adding Labels
- Adding Title
- Grid
- Legend

### Figure Customization

- Figure Size
- DPI
- Saving Figures

## 🎯 Learning Outcomes

After completing this lesson, I can:

- Understand Matplotlib's architecture.
- Create figures and axes.
- Generate basic line plots.
- Customize titles, labels, legends, and grids.

## ⚡ Quick Revision

| Function | Purpose |
|----------|---------|
| plt.figure() | Create Figure |
| plt.plot() | Line Plot |
| plt.xlabel() | X-axis Label |
| plt.ylabel() | Y-axis Label |
| plt.title() | Plot Title |
| plt.legend() | Add Legend |
| plt.grid() | Add Grid |
| plt.savefig() | Save Figure |
| plt.show() | Display Plot |
